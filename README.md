# SALVAGE SHIFT — 웹 빌드

싱글 익스트랙션 로그라이트 프로토타입의 웹(WebGL) 빌드입니다. GitHub Pages로 배포합니다.

- 플레이: https://sinoso.github.io/salvage-shift-web/
- 데스크톱 브라우저(Chrome·Edge·Firefox) 기준. 키보드·마우스 또는 게임패드.
- 빌드: Unity 6000.5.9f1, WebGL 2, Brotli 압축 + 압축 해제 대체(서버가 압축 헤더를 붙이지 않아도 열린다).
- 지금 판: 0.12.0 (11~12주차 플레이테스트 판 — 소리, 계약 조건 2개, 경쟁사 알림, 넓힌 구역, 할당량 5,000cr). 웹 판은 플레이 기록 파일을 남기지 않습니다.
- 소스는 별도 비공개 저장소에 있습니다. 이 저장소에는 빌드 결과물만 있습니다.
